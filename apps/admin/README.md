# Shadcn Dashboard

A dashboard UI built with Next.js, shadcn/ui, Tailwind CSS, and TanStack Table.

## Live Demo

Available on:

1. [Dashboard](https://petrikba.github.io/shadcn-dashboard/)
2. [Payments](https://petrikba.github.io/shadcn-dashboard/payments)
3. [Users Detail](https://petrikba.github.io/shadcn-dashboard/users/test)

## Local Development

Run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Table
